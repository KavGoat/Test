# Asbestos Removal Programme – transfer into AAD template

**Output:** `AAD-OE-WSP-STW-0000-RPT-000002_Asbestos_Removal_Programme_B_AAD-Template.docx`
(plus a LibreOffice PDF preview of the same file).

The new file is the AAD template package (its styles, numbering, theme, headers, page setup and
cover artwork are untouched) with the report content from the WSP document placed into it.
The file passes OOXML schema validation.

## 2. Content check (new document vs. content document)

Method: both files converted to plain text with pandoc, body text from "Introduction" onward compared
line by line after stripping heading numbers and bullet markers.

- **Body text:** identical. The only differences are the appendix headings, where the manual
  "Appendix A –" prefix is now generated by the template's numbering, and the source's container
  heading "9 Appendix" which the template does not use.
- **Front matter:** every cover, sign-off, revision and abbreviation string from the source is present.
- **Tables:** all 5 content tables, all rows and cells, including the four `=SUM(LEFT)` formula fields in Table 3.
- **Cross-references:** all 8 `REF` fields and their target bookmarks are present and matched
  (Table 2, Table 3, Table 1, Table 4, Figure 1, Figure 2, Section 4, Section 3.6). Section numbers are
  unchanged (Prioritisation is still section 4, Key Assumptions still 3.6), so the cached results are correct.
- **Captions:** 5 table and 2 figure SEQ fields present.
- **Equations:** the three equations compare identical when extracted as LaTeX from both files.
- **Images:** 3 signatures, Figure 1 SmartArt and Figure 2 chart present and linked.
- **Comments:** the source's 6 review comments were not carried over (they are review markup, not content).
  For reference they were: three empty comments on the signature images; "Update dates as per new registers
  provided." / "Done" on the Casey register date; and "Proposed?" from Will Parker on the second paragraph
  of section 8 (Davis Station ARP).

## 3. Formatting check (new document vs. template)

- **Page setup, sections, headers:** the two section definitions are byte-identical to the template
  (A4, 2 cm margins, AAD logo header on the first page).
- **Styles:** every paragraph style used exists in the template. Styles used: Heading 1, AAD H2 Heading 2,
  Heading 3, Heading 4, Body Text, List Bullet, Caption, Tableheading, Table Text, Table Bullet, Table text
  (cover tables), Heading 1 no number (Abbreviations page), Appendix Heading, Appendix Heading 2, TOC 1/2,
  TOC Heading. Appendix Heading 2 is defined in the template but was not used in the sample pages.
- **Tables:** body tables use the template's table style with full-width fixed layout; cover tables are the
  template's own tables with the cells filled.
- **Direct formatting:** none other than bold lead-ins inside bullets (as in the source), the two cyan
  highlighted placeholders, one superscript (m³) and `noProof` on images. No fonts, sizes or colours were
  carried over from the WSP document.
- **Package parts:** the only template parts changed are document.xml, its relationships, content types and
  the core properties (title). New parts are the 4 images and the 5 SmartArt diagram parts.
- **Table of contents:** rebuilt with the template's TOC field, levels 1–2 plus appendices. The field is
  flagged for update, so Word refreshes page numbers when the file is opened (answer Yes if prompted,
  or press F9).
