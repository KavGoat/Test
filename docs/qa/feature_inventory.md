# Feature inventory

Generated by `tools/qa/inventory.py` from commit cbdd356: the real MainWindow, headless (QT_QPA_PLATFORM=offscreen). Regenerate it rather than edit it:
`QT_QPA_PLATFORM=offscreen python tools/qa/inventory.py` (about ten minutes on a loaded machine).

The denominator for the passes in [QA_PLAN.md](QA_PLAN.md): every user-reachable feature once, with a test that exercises it.

How it was walked: the menu bar with every lazy submenu asked to fill (`aboutToShow`), in six states (fresh; two shapes selected; two pages; a table open; a spreadsheet page open; Calc mode); every toolbar and the status bar in those states; every panel, its title-bar buttons and its own menus; right-click menus built by the app's own builders, with real right-clicks on the canvas, on one of every markup the tools draw headlessly, a multi-selection, an equation, a calculation block and text, table and spreadsheet cells, thumbnails, the document tab, the Markups List, the Tool Chest, the Variables panel, the ruler and the sheet tabs. Dialogs, keys and mouse gestures come from the source: every QDialog subclass and input box in `calcforge/ui`, the shortcut registry (`ShortcutManager.bindings()`) plus the fixed keys and gestures in `view.py`.

**Covered by** is a grep of `tests/`, not a run: the first test that triggers the action or calls the method behind the entry (or picks the tool, or presses the key). `≈` means a test only names it (its attribute or its label, often a menu-wording check): weaker than exercising it. For keys, `key:` means a test sends that key with exactly those modifiers; `cmd:` means only the command is tested, not its key. `(+n)` counts further matching tests. A value list (paper sizes, decimal places, widths) is one line.
