# CalcForge completed-work evidence

Last audited: 2026-09-06

This file lists requirements for which the current source has implementation and validation evidence. It is provided for user review and is not the authoritative completion record. Only the user marks completion in `docs/tasklist.xlsx` or changes task checkboxes.

## Audit note, 2026-09-06

This file was created at commit `cad6468`, in the same change that reduced `docs/UNADDRESSED_TASKS.md` from 125 items to 5. The full suite was re-run at that commit as part of auditing it: 1254 tests, 11 failures. Three were an environment fault (`cryptography` without `_cffi_backend`) and not the branch's. The remaining eight were real, and two of them were cited as evidence by entries in this file — the two page-menu entries below, whose wording has been corrected to match what the code now does. The failures are fixed in `c91d4f3` and the suite is green at 1254 passed, verified against the running application as well as the harness.

Every one of the 66 test names cited in this file exists in `tests/`. That is not on its own evidence that the behaviour still holds: the two entries below cited tests that were failing at the time the claim was written.

## Calculation and equation editing

- The live calculation pass builds an ordered variable dependency graph for calculation lines, blocks, and tables. Redefining a variable refreshes only the changed node and its transitive downstream consumers, while unaffected cached outputs are safely replayed into a clean reading-order workspace; structural changes fall back to a full live pass and the independent verifier remains a full source re-evaluation. Evidence: three focused dependency/redefinition/cache-rebuild tests, 110 calculation/table/unit focused tests, and 145 verifier/validation/property tests passed on 2026-09-05.
- Quote is the sole calculation-entry trigger; slash remains division inside equations. A space converts either a fresh or re-entered single calculation line to text at the caret, while calculation blocks reject spaces and explain why. Evidence: ten focused real-event entry, conversion, block, slash, and shortcut tests passed on 2026-09-05.
- Backspace, Escape, `=`, and ordinary characters survive focus loss and return while an equation remains open. Evidence: `test_the_calculation_keys_survive_the_keyboard_wandering_off`, `test_a_menu_over_a_calculation_does_not_close_it`.
- The result `=` can be typed, deleted, and retyped through the real event path; its old fixed ten-pixel gutter is migrated to a compact four-pixel mathematical spacing. Focus loss, menu use, and definition-name return remain covered. Evidence: seven focused equation-key/focus/spacing tests and four engine equals-semantics tests passed on 2026-09-05.
- Known equation-spacing inconsistencies are normalized: results use the compact mathematical gutter, number–unit products are joined tightly while ordinary multiplication retains operator spacing, powers ride the visible shoulder of their base, and subscript-plus-power scripts share one column. Degenerate headless Qt font metrics use a narrow x-height/ascender fallback without overriding real font outlines. Evidence: all five focused result/unit/product/exponent/script spacing tests passed on 2026-09-06.
- Wrong-case units are recognized and canonical suggestions are offered. Evidence: unit-completion and engine suggestion tests.
- Directly attached recognized units, including one-letter `m`, render in unit blue both while typing and at rest. Evidence: `test_a_one_letter_unit_is_blue_while_typed_and_at_rest` plus the engine suite, 58 focused tests passed on 2026-09-05.

## PDF, import, and persistence

- Opening a `.pdf` through File → Open creates a focused PDF-review document rather than a worksheet: original pages are imported at full fidelity, calculation line/block/table/plot entry and calculation-only menus, symbols, status, panels and commands are hidden or disabled, while navigation, markups, measurements, scale, Snapshot, save and export remain available. The `pdf` mode persists in `.cfx`, Save cannot overwrite the source PDF, and returning to a new worksheet restores its calculation UI. Evidence: three focused real-action/key mode tests and the broader PDF/Snapshot/menu group passed all 26 tests on 2026-09-06.
- Insert PDF retains the original PDF bytes and source-page index alongside the screen preview, carries both through `.cfx` save/reopen and uses the original page as the base of exported PDFs. CalcForge content is painted as a transparent overlay, reconstructed snap linework is suppressed to avoid duplication, and incompatible destructive page operations deliberately discard the original source reference. A malformed source falls back to the visible raster preview instead of preventing export. Evidence: four focused import/persistence/visual-export/selectable-text tests passed, and the broader PDF/export/print group passed all 12 tests on 2026-09-06.
- Snapshot uses G in both worksheet and PDF-review modes and records PDF/vector drawing plus ordinary markups as one persistent vector item without the page background. Calculation, table and text content is excluded unless explicitly selected before the Snapshot drag, and that prior selection now survives marquee completion. The external image clipboard is rasterised from the same filtered vector recording, so excluded content is not reintroduced there. A pasted PDF-region Snapshot remains intact through subsequent editing, `.cfx` save/reopen and PDF export. Evidence: all 12 Snapshot usability tests plus the real PDF-review persistence/export regression passed on 2026-09-06; the broader PDF/Snapshot/menu group passed all 26 tests.
- Flatten Selection works on individual items, while Flatten opens a document-wide chooser for markups, calculations and tables. Recoverable flattening is the default and retains complete source items through serialization for the global Recover command, including their prior lock state.
